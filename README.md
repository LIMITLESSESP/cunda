# Cunda

Intervalos de estudio con objetivo de páginas: eliges qué vas a estudiar, hasta qué página quieres llegar y cuánto tiempo le das, y Cunda te enseña dónde deberías ir sin distraerte.

**Menos horas. Más temario.**

Web instalable en [cunda.es](https://cunda.es). En el iPhone: ábrela en Safari → Compartir → Añadir a pantalla de inicio.

Tus datos se quedan en tu móvil: Cunda no tiene servidor ni cuentas.
